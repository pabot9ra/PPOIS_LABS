# Машина Поста

Лабораторная работа №1 по ППОИС, вариант 1.8.1.
Автор: Владислав Вертинский.

Интерпретатор машины Поста: бесконечная в обе стороны лента, каретка и программа из шести видов команд. Работает в двух режимах - консольное меню и выполнение программы из файла.

## Сборка

Нужны `g++`/`clang++` с поддержкой C++17 и `make`. Для тестов - UnitTest++:

```sh
brew install unittest-cpp
```

Пути к UnitTest++ в `Makefile` указаны для Homebrew на Apple Silicon (`/opt/homebrew`). На другой системе поправьте переменные `UT_INC` и `UT_LIB`.

```sh
make          # собрать prog и tests
make test     # собрать и запустить юнит-тесты
make clean    # удалить собранные файлы
```

Документация (нужен doxygen):

```sh
doxygen Doxyfile    # результат в html/index.html
```

## Запуск

```sh
./prog                     # консольное меню
./prog example.txt         # выполнить программу из файла, вывести начальное и конечное состояние
./prog example.txt -log    # то же, но с выводом состояния после каждого шага
```

При запуске с файлом выполняется не больше 10000 шагов - защита от бесконечного цикла.

Коды возврата:

| Код | Когда |
|-----|-------|
| 0 | машина остановилась на команде `!` |
| 1 | файл не открылся, неверный формат файла, ошибка выполнения или исчерпан лимит шагов |

## Формат файла

```
tape: 0 V
carriage: 0
-> 2
? 1, 3
V 4
!
```

- `tape:` - номер первой ячейки и её содержимое подряд, без пробелов: `V` - метка, `.` - пусто. Например, `-2 V.VV` помечает ячейки -2, 0 и 1. Остальные ячейки ленты пустые.
- `carriage:` - номер ячейки, над которой стоит каретка.
- Дальше - команды, по одной на строку, до конца файла. Команды нумеруются с 1 в порядке следования.

Команды:

| Запись | Действие |
|--------|----------|
| `V n` | поставить метку под кареткой, перейти к команде n |
| `X n` | стереть метку под кареткой, перейти к команде n |
| `-> n` | сдвинуть каретку вправо, перейти к команде n |
| `<- n` | сдвинуть каретку влево, перейти к команде n |
| `? n1, n2` | если под кареткой метка - перейти к n1, иначе к n2 |
| `!` | остановить машину |

Ошибкой выполнения считаются: `V` на помеченной ячейке, `X` на пустой ячейке и переход на несуществующую команду.

Пример из `example.txt` прибавляет 1 к унарному числу: из ленты `V` получается `V V` за 4 шага.

## Меню

Пункты: загрузить машину из файла, показать машину, показать программу, добавить команду, удалить команду, задать ленту, задать позицию каретки, сделать шаг, выполнить до конца с лимитом шагов, сбросить, выход.

«Сбросить» возвращает машину к команде 1 и состоянию «работает», но не меняет ленту и каретку.

## Структура

| Файл | Содержимое |
|------|-----------|
| `tape.h/.cpp` | класс `Tape` - лента |
| `instruction.h/.cpp` | класс `Instruction` и `enum class OpType` - команда |
| `program.h/.cpp` | класс `Program` - список команд |
| `postmachine.h/.cpp` | класс `PostMachine` и `enum class State` - машина |
| `menu.h/.cpp` | консольное меню |
| `main.cpp` | точка входа: меню или выполнение файла |
| `tests.cpp` | 30 юнит-тестов на UnitTest++ |
| `example.txt` | пример программы |
