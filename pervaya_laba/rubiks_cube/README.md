# Кубик Рубика

Лабораторная работа №1 по ППОИС, вариант 1.5.3.
Автор: Владислав Вертинский.

Кубик Рубика 3×3: случайное перемешивание, загрузка начальной расстановки цветов из файла, поворот любой грани в обе стороны и на 180°, проверка, собран ли кубик. Работа с кубиком - через консольное меню.

## Сборка

Нужны `g++`/`clang++` с поддержкой C++17 и `make`. Для тестов - UnitTest++:

```sh
brew install unittest-cpp
```

Пути к UnitTest++ в `Makefile` указаны для Homebrew на Apple Silicon (`/opt/homebrew`). На другой системе поправьте переменные `UT_INC` и `UT_LIB`.

```sh
make          # собрать prog и tests
make test     # собрать и запустить юнит-тесты
make clean    # удалить собранные файлы
```

Документация (нужен doxygen):

```sh
doxygen Doxyfile    # результат в html/index.html
```

## Запуск

```sh
./prog
```

## Меню

| Пункт | Действие |
|-------|----------|
| 1 | загрузить кубик из файла |
| 2 | показать кубик развёрткой |
| 3 | проверить, собран ли кубик |
| 4 | перемешать кубик 25 случайными ходами |
| 5 | сделать ход: выбрать грань (1-6) и направление (1-3) |
| 6 | сбросить кубик в собранное состояние |
| 0 | выход |

Грани в пункте 5: верхняя, левая, передняя, правая, задняя, нижняя. Направления: по часовой, против часовой, на 180°. Направление считается, если смотреть прямо на поворачиваемую грань.

Перемешивание делается случайными ходами, а не случайной расстановкой цветов, поэтому перемешанный кубик всегда можно собрать.

## Формат файла

Развёртка буквами - тот же вид, в котором кубик выводится в пункте 2:

```
      R B O
      O W B
      Y G Y
B B G O R O B W G W Y Y
G O Y R G G O R O Y B W
W W Y G Y B W O W R R R
      R G O
      R Y W
      B B G
```

- сверху грань U (верхняя), в середине подряд грани L, F, R, B (левая, передняя, правая, задняя), внизу грань D (нижняя);
- каждая грань записывается по рядам сверху вниз, если смотреть прямо на неё;
- цвета: `W` - белый, `Y` - жёлтый, `R` - красный, `O` - оранжевый, `G` - зелёный, `B` - синий;
- пробелы и переводы строк не важны: читаются 54 буквы подряд.

Файл отвергается, если в нём неизвестная буква, меньше 54 букв, какого-то цвета не ровно 9 или у двух граней одинаковый центр. В этом случае текущий кубик не меняется. Полная проверка того, что кубик из файла можно собрать, не делается.

Собранный кубик - белый верх, оранжевый слева, зелёный спереди, красный справа, синий сзади, жёлтый низ.
